# Java Logic Practice 🧠☕

A hands-on collection of Java programming problems solved to strengthen problem-solving skills, master programming fundamentals, and build a solid foundation for Data Structures and Algorithms (DSA).

I focus on **understanding the logic, writing the code myself, optimizing solutions, and documenting what I learn** — not memorizing answers.

## 🎯 Goals

- Solve one new programming problem regularly.
- Strengthen Java fundamentals through practical coding.
- Understand algorithms before optimizing them.
- Practice time and space complexity.
- Build a strong foundation for DSA and technical interviews.
- Track progress through Git, GitHub, branches, and pull requests.

## 🔄 Development Workflow

1. Create a feature branch from the latest `main`.
2. Solve and test a Java problem.
3. Commit the solution with a descriptive message.
4. Open a pull request.
5. Run automated Java compilation checks.
6. Review and merge the pull request.
